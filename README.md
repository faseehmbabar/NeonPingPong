# NeonPingPong 🏓
A neon-themed arcade Ping Pong game built in C++. Developed as a university programming assignment.

## Features
- Smooth arcade physics & scoring system
- Retro-futuristic neon visual style

## Controls
- **Player 1:** `W` / `S` keys
- **Player 2:** Up / Down arrows

## How to Build & Run
1. Ensure you have CMake and a C++ compiler installed.
